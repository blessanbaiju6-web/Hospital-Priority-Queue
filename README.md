Hospital Priority Queue

A simple C program that implements a Priority Queue to manage patients in a hospital.

Patients are treated according to their priority rather than only their arrival time. Priority 1 represents the highest priority, followed by Priority 2 and Priority 3. If patients have the same priority, they are treated in the order they were added.

Features

- Add patients to the queue
- Assign priority to patients
- Treat patients based on priority
- Maintain arrival order for equal priorities
- Demonstrates the practical use of a Priority Queue
